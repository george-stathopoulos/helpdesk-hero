# Helpdesk Hero

**Get help from your support team, safely, without sharing passwords.**

The free WordPress plugin your customers install to open support tickets from their dashboard, with their site's details attached, and to give your team temporary, password-free access that ends on its own. It connects to your team's [Helpdesk Hero Hub](https://github.com/george-stathopoulos/helpdesk-hero-hub) with a one-time code.

- Tickets with WordPress, PHP and server versions, plugins, recent errors, recent changes and a health check
- Temporary support accounts with one-time login links; everything support does is logged for the site owner
- Troubleshooting mode: support can switch plugins off for their own session only
- Replies, tags, ratings and dashboard messages from the support team

**Documentation:** [docs/](docs/README.md) in this repository, with screenshots ([Getting started](docs/getting-started.md), [FAQ](docs/faq.md), [Troubleshooting](docs/troubleshooting.md)).

**Website, help center and live demo:** https://george-stathopoulos.github.io/helpdesk-hero/

## In this repository

This is the plugin as it ships: PHP in `includes/`, the dashboard's source in `src/` and its compiled bundle in `build/`. Download the installable zip from the [latest release](../../releases/latest), then upload it under **Plugins → Add New → Upload Plugin**.
